Eco-Loop Cognitive Architecture

A 5-layer autonomous system coordinating multiple specialized LLM agents.

1. Perception Layer

Aggregates raw 1-minute EnergyPlus sensor data into a compressed 30-minute state. The Anomaly Detector flags impossible physics (e.g., a broken sensor reporting -40°C) before it pollutes the LLM context.

Tools: get_building_state(), get_anomaly_report()

2. Memory Layer

Maintains persistent state across ticks. When agents prompt the LLM, they inject the last 3 decisions and whether those decisions were overridden or clamped. This enables true self-correction.

Tools: get_my_last_decisions(), get_performance_summary()

3. Planning Layer

The Forecast Planner Agent runs conditionally every 6 hours. It analyzes the 24-hour weather forecast and grid carbon curve to set a high-level strategy (e.g., "Pre-cool overnight") and a peak kW cap.

Tools: get_weather_forecast(), get_grid_carbon(), set_strategy()

4. Reasoning Layer

5 Zone Agents run concurrently via asyncio.gather, proposing local setpoints. The Coordinator Agent then collects all 5 proposals, checks them against the Planner's kW cap, and forces compromises if needed.

Tools: propose_zone_setpoint(), get_all_zone_proposals(), approve_setpoints()

5. Safety Layer

The ultimate veto. The Comfort Auditor independently verifies PMV. If limits are breached, it issues an emergency override. Finally, the deterministic Guardrail Engine enforces physical rate-limits before hitting the actuators.

Tools: get_all_zone_pmv(), issue_comfort_override()
