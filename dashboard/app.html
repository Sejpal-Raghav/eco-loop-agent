Architecture
5-layer cognitive control system coordinated over MCP
01 Perception Layer Always active
Raw 1-minute EnergyPlus sensor readings are compressed into 30-minute state snapshots. The Anomaly Detector flags physically impossible values before they reach any LLM, preventing context pollution from broken sensors.
get_building_state() · get_zone_state() · get_anomaly_report()
02 Memory Layer Persistent across ticks
Each agent prompt is injected with the last 3 decisions and whether they were overridden. If a proposal was guardrail-clamped, the next tick the agent reads that feedback and self-corrects—no retraining required.
get_my_last_decisions() · get_performance_summary()
03 Planning Layer Conditional · every 6 h
The Forecast Planner reads the 24-hour weather and grid carbon curve every 6 simulation hours. It outputs a named strategy and a peak kW cap consumed by all downstream agents on every subsequent tick.
get_weather_forecast() · get_grid_carbon() · set_strategy() · get_current_strategy()
04 Reasoning Layer Every tick · parallel + sequential
Five Zone Agents run concurrently via asyncio.gather, each proposing setpoints for their specific zone. The Coordinator collects all proposals, checks total kW against the Planner's cap, and negotiates compromises under load pressure.
propose_zone_setpoint() · get_all_zone_proposals() · approve_setpoints()
05 Safety Layer Hard veto · every tick
The Comfort Auditor independently monitors all PMV readings. If any zone exceeds ±0.5, it issues an emergency override that bypasses the Coordinator entirely. The deterministic Guardrail Engine then enforces rate limits (max 3 °C/tick) and hard floor/ceiling bounds before actuator commands are issued.
get_all_zone_pmv() · issue_comfort_override()
